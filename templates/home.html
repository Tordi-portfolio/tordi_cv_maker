About This Project

This CV Maker was built to streamline the job application process for tech professionals. It focuses on clean data entry and professional PDF generation.

Technical Implementation

  • Backend: Django 6.0 with SQLite database.
  • Frontend: Tailwind CSS for responsive, modern UI components.
  • PDF Generation: Custom server-side rendering using xhtml2pdf.
  • Auth System: Secure user accounts to manage and store personal CV data.
